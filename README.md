# Río Hondo College Public

This site is developed in an internal GitHub Enterprise repository and published here for hosting through GitHub Pages.

## Report a problem

Open an [Issue](../../issues/new/choose) when you have identified a specific problem with the published site, such as:

- A page or card does not load.
- A link is broken or points to the wrong destination.
- A site asset, image, or document is missing.
- A published page displays an obvious error.

When reporting a problem, please include:

- The page or card URL.
- The link or feature that is not working.
- The steps needed to reproduce the problem.
- The browser and device, if relevant.
- Any error message or screenshot that does not contain private or sensitive information.

## Ask a question or start a conversation

Start a [Discussion](https://github.com/Rio-Hondo-College-Public/rio-hondo-college-public.github.io/discussions) for questions, suggestions, or topics that may benefit from conversation before becoming a specific bug report. Examples include:

- Questions about how a public page or link is intended to work.
- Suggestions for improving the public site.
- Ideas for future cards or pages.
- General feedback about the published site.

## Before submitting

Please search existing [Issues](../../issues) and [Discussions](../../discussions) before creating a new topic. This helps avoid duplicate reports and keeps related information together.
